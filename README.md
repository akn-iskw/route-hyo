# ルート表（有料老人ホーム 曜日別ルート表）

ナーシングホーム寿々デンタル中村の、曜日ごとの利用者ルート表を管理・印刷するWebアプリです。
GitHub Pages で公開し、データは Supabase に保存します。

## できること

| 画面 | 内容 |
|---|---|
| ルート編集 | 曜日×30分枠×利用者のマスをプルダウンで選ぶだけ。選んだ瞬間に保存。区分の色でマスが塗られます。曜日まるごと／利用者ごとに他の曜日へコピーできます。曜日ごとのメモ（例：週一回の風呂掃除）も入れられます |
| 利用者 | 部屋番号と名前で追加。「○○さんと同じ予定で作る」でコピーから作成可。入院・退去は「表示」を外すと予定を残したまま隠せます |
| 項目・色 | 区分（看護・介護・施設サービス・STリハ）ごとに色を自由に選べます。プルダウンの項目の追加・名前変更・並べ替え・非表示 |
| 確定する | 編集は「下書き」。編集画面の「確定する」を押した時点の内容が確定版になります（未確定の変更件数が表示されます） |
| ルート表（確定） | 確定版を見るだけの画面。曜日ごと／人ごと（1人1枚・月〜日）、時間帯（日中・夜勤・全日）、区分（看護だけ等）を選んで、印刷・Excel・PDFでダウンロード |

夜勤の印刷は、たとえば「月曜日 夜勤」なら 月曜16:30〜23:30 ＋ 火曜0:00〜9:30 をつなげて1枚にしています。

## ファイル構成

```
index.html      画面
app.js          動き（Supabase／デモモード両対応）
style.css       見た目・印刷レイアウト
config.js       ★ Supabase の URL と anon key を書く場所
demo-data.js    デモモード用の初期データ
sql/01_schema.sql  テーブル作成（最初に1回）
sql/02_seed.sql    初期データ投入（Excel 10月23日現在の内容、最初に1回）
sql/03_kakutei.sql 確定版テーブルの追加（最初に1回）
lib/               Excel・PDF出力用のライブラリ（ExcelJS・jsPDF・html2canvas）
```

## 公開までの手順

### 1. Supabase にテーブルを作る
1. Supabase のダッシュボード → 使うプロジェクト（社員名簿・議事録と同じプロジェクトでOK）→ **SQL Editor**
2. `sql/01_schema.sql` の中身を貼り付けて **Run**
3. 続けて `sql/02_seed.sql` の中身を貼り付けて **Run**（利用者8名・項目40個・予定682件が入ります）
4. 続けて `sql/03_kakutei.sql` の中身を貼り付けて **Run**

テーブル名はすべて `route_` で始まるので、既存アプリのテーブルとはぶつかりません。

### 2. config.js を書き換える
Supabase の **Project Settings → API** にある
- Project URL → `SUPABASE_URL`
- anon public key → `SUPABASE_ANON_KEY`

を `config.js` に貼り付けます（service_role key は絶対に入れないでください）。

### 3. GitHub Pages で公開
1. GitHub で新しいリポジトリを作成（例：`route-hyo`）
2. このフォルダの中身をすべてアップロード（Add file → Upload files）
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後、`https://akn-iskw.github.io/route-hyo/` で開けます

### 4. ログイン
Supabase の Authentication に登録されているメールアドレスとパスワードでログインします。
同じプロジェクトを使っている場合、社員名簿・議事録と同じアカウントでそのまま入れます。
新しく使う人は Supabase → Authentication → Users → **Add user** で追加してください。

> 権限について：今の設定では「ログインできる人は全員、閲覧・編集できる」です。
> 閲覧だけの人を作りたい場合は、議事録と同じ permissions テーブル方式に広げられます。

## デモモード
`config.js` が空のままだと、Supabase につながずに動く「デモモード」になります（このブラウザの中だけに保存）。
試しに触ってみるとき用です。画面上部の「初期データに戻す」で元に戻せます。

## 印刷のコツ
- ブラウザの印刷画面で「余白：デフォルト」「倍率：100％」
- 色が出ないときは「背景のグラフィック」をオン
- 用紙サイズはアプリ側で A4／A3 を選ぶと自動で合わせます
